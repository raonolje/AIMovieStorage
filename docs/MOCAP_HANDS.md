# 영상에서 손가락 움직임 가져오기

**개발 브랜치 미리보기입니다. v0.2.3 배포본에는 포함되어 있지 않습니다.** 아래는 현재 소스의 사용법과 검증 범위입니다. 새 공개 설치본의 배포 완료를 뜻하지 않습니다.

몸 분석에 양손의 관절 좌표를 더해 구도잡기의 손목·손가락 키로 옮깁니다. 손마다 손목을 포함한 21점을 읽고, 리그에 필요한 본이 있으면 한 손 15마디, 양손 합계 30마디의 손가락 회전을 만듭니다. 손목 회전은 별도로 맞춥니다. 몸의 33점만으로 손가락 굽힘을 추정하지 않습니다.

## SAM 3D Body로 몸과 손을 함께 분석하기

1. 설정에서 SAM 3D Body를 설치합니다. 모델 다운로드에는 해당 모델의 접근 승인과 Hugging Face 토큰이 필요할 수 있습니다.
2. **구도잡기 → 타임라인 → 영상 올려서 캐릭터에 모션 입히기**를 열고 원본 영상을 선택합니다.
3. 분석 모델을 **SAM 3D Body**로 고릅니다. **손가락 함께 분석**은 기본으로 켜져 있습니다.
4. 구간·분석 장수·거울 영상 여부를 정한 뒤 **사람 찾기 · 관절 분석**을 누릅니다. 다른 분석이 진행 중이면 같은 작업 줄에 들어갑니다.
5. 결과를 확인하고 영상 속 사람 번호를 캐릭터와 연결한 뒤 **타임라인에 넣기**를 누릅니다.

손 옵션을 켜면 SAM의 몸·손 decoder를 함께 실행하는 `full` 경로를 사용합니다. 끄면 `body` 경로로 몸만 분석하고 손 전용 결과는 만들지 않습니다. 손 분석은 추가 연산과 메모리를 요구할 수 있으며, 현재 개발 환경에서 SAM `full`의 GPU 시간·메모리·정확도를 실측하지는 않았습니다.

## 기존 몸 분석에 MediaPipe 손 추적 추가하기

1. 먼저 위 창에서 **몸 분석을 완료**하거나 저장된 몸 분석 결과를 불러옵니다.
2. 영상을 선택하고 **손가락 추가 추적 · MediaPipe**를 누릅니다.
3. 기존 몸 분석과 같은 시각의 프레임을 다시 읽어 손을 찾습니다. 몸 분석과 같은 작업 줄을 사용하며 진행 상태 확인과 취소가 가능합니다.
4. 결과 파일 저장이 끝난 뒤 사람·캐릭터 연결과 미리보기를 확인하고 **타임라인에 넣기**를 다시 누릅니다. 분석 완료만으로 장면의 기존 키를 자동으로 바꾸지는 않습니다.

MediaPipe Hand Landmarker 모델 약 **7.8 MB**와 실행에 필요한 WASM은 앱에 포함됩니다. 모델을 사용하기 위해 별도 API 키를 넣거나 실행 때 인터넷에서 가중치를 받을 필요는 없습니다. 영상은 PC에서 프레임으로 읽어 처리하며, 이 손 추적 경로는 **원본 영상이나 프레임을 외부 서버에 업로드하지 않습니다**. 데스크톱 앱에서 원본 영상 파일을 읽을 수 있어야 합니다.

각 검출 손은 같은 시각의 몸 손목과 화면상 거리를 비교해 사람과 좌우를 연결합니다. 검출기의 좌우 이름만으로 연결하지 않습니다. 팔을 교차하거나 사람이 겹쳐 어느 손목인지 명확하지 않으면 새 결과를 붙이지 않고 해당 프레임의 기존 손 데이터를 남깁니다. 원본 분석은 새 결과 파일 저장에 성공한 뒤 교체합니다.

## 기존 편집을 보존하는 범위

- 손이 검출되지 않은 프레임에는 손 데이터를 임의로 채우지 않습니다. 평활화도 손 미검출 구간을 넘어 연결하지 않습니다.
- 손 추가 추적에서 한쪽만 명확하게 검출되면 그쪽만 갱신합니다. 다른 손의 기존 분석 결과는 유지합니다.
- 타임라인 적용 시 검출된 마디만 새 회전으로 바꿉니다. 미검출 마디의 기존 손가락 키는 **캡처 프레임 사이에 있던 시각과 그때의 값도 보존**합니다. 적용 구간 밖의 키는 유지합니다.
- **0도 검출**과 **미검출**을 구분합니다. 실제로 손가락을 편 결과는 기존 굽힘을 0도로 바꿀 수 있습니다.
- 몸과 손은 하나의 자세 키에서 완급 곡선(easing)을 공유합니다. 기존 손 키의 시각·값은 유지하지만, 새 몸 움직임과 서로 다른 원래 손 곡선을 동시에 완전히 재현하는 것은 현재 저장 형식으로 보장하지 않습니다. 적용 후 재생을 확인하고 필요한 키를 조정하세요.

## 검증한 것과 남은 것

| 확인 방법 | 확인 범위 |
| --- | --- |
| 실제 MediaPipe 모델 · 공식 예제 정지사진 | `thumb_up`, `pointing_up` 사진 각각에서 손 21점 검출 확인 |
| 실제 영상 프레임 경로 | 예제 사진을 전환하는 512픽셀·1.2초 MP4의 0.1·0.3·0.8·1.0초에서 각각 손 21점 확인. 실제 춤 동작 영상은 아님 |
| 실제 검출 좌표→리타깃 | 위 4개 프레임의 좌표를 실제 남성 GLB 리그에 넘겨 매 프레임 왼손 15마디 회전 출력 확인. 원본 몸 분석이 바뀌지 않는 것도 확인 |
| 앱의 실제 GLB 리그를 사용한 회귀시험 | 양손 30마디의 방향을 좌표→회전→재생으로 재현하고, 키 순서가 달라도 같은 결과인지 확인 |
| 저장·보정·적용 시험 | JSON 손 좌표 보존, 좌우 반전, 미검출 구간 유지, 수동 손 키 보존, 저장 실패와 취소 처리 확인. 실제 모델 실행 후 검출기·WebGL 자원 정리도 확인 |
| SAM 워커 모의시험 | 공식 MHR70 관절 순서, 양손 21점 변환, 몸과 같은 좌표계, `full`/`body` 선택과 결과 JSON 확인. GPU 추론은 미실행 |

실제 모델을 실행하며 SDK의 미제공 `visibility`가 0으로 채워지는 경우를 확인했고, 이를 모든 관절의 미검출로 해석하던 문제를 수정했습니다. 현재 MediaPipe와 SAM 손 결과의 관절별 유효성은 화면 안/밖 및 유한 좌표 여부 등을 확인하는 기준입니다. **실제 가림 확률이나 손가락 정확도 점수를 측정한 값은 아닙니다.**

작은 손, 빠른 움직임, 흐린 영상, 몸이나 물체에 가려진 손, 여러 사람이 겹친 장면에서는 잘못된 검출이나 누락이 생길 수 있습니다. 실제 댄스 영상, 긴 영상, SAM `full` GPU 추론과 새 공개 설치본의 전체 사용자 흐름 검증은 남아 있습니다. 손가락 끝 본이 없는 사용자 리그에서는 해당 마디를 적용하지 않습니다.

## 번들 모델과 라이선스

포함된 파일은 Google의 `hand_landmarker/hand_landmarker/float16/1` 번들입니다. 크기·해시·다운로드 출처는 [모델 고지](../client/public/models/hand_landmarker.NOTICE.md)에 있으며, [Apache 2.0 라이선스 전문](../client/public/models/hand_landmarker.LICENSE.txt)을 함께 제공합니다.

가중치의 근거는 코드 저장소의 라이선스가 아니라, [Google 공식 모델 안내](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker)의 Models 표에서 연결한 [Hand Tracking 모델 카드](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20%28Lite_Full%29%20with%20Fairness%20Oct%202021.pdf)입니다. 해당 카드 2쪽에 Apache License 2.0이 명시되어 있습니다. 앱 코드의 MIT 라이선스와 모델의 고지를 구분해 유지합니다.

SAM 3D Body의 별도 다운로드 모델은 해당 모델의 라이선스와 접근 조건을 따릅니다. MediaPipe 번들 라이선스를 다른 모델에 일괄 적용하지 않습니다.
