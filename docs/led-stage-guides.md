# LED 크롭 가이드와 배우 실루엣

구도잡기와 이미지 편집의 **LED 가이드** 탭은 같은 공용 편집기를 사용합니다.
카메라 비율 또는 원본 이미지의 실제 종횡비를 기준으로 표시하며, 원본 픽셀은 바꾸지 않습니다.

- 영역은 32개까지 추가할 수 있습니다. 이름·색·개별 표시를 정합니다.
- 비율 가로·높이는 LED 픽셀 수 또는 가로·세로 비례값으로 입력합니다.
- 화면 가로/높이 맞춤은 위치와 독립적입니다. 맞춤 후에도 끌거나 위치 수치로 옮길 수 있습니다.
- 오른쪽 아래 손잡이 또는 폭 수치로 조절하면 자유 크기로 전환하며 입력 비율을 유지합니다.
- 영상 밖 영역은 경고합니다. 꺾인 LED의 구역을 표현하기 위해 일부러 밖으로 옮기는 것도 허용합니다.
- LED 편집 중에는 렌즈·무빙 타임라인 도구를 숨겨 프레임 전체와 손잡이를 확인할 수 있습니다.

## 배우 높이

기준 LED 영역의 실제 높이와 배우 키를 입력하고, LED 앞 거리와 관객에서 LED까지 거리를 정합니다.

`LED 대비 배우 화면 높이 = (배우 키(m) / LED 실제 높이(m)) × 관객-LED 거리 / (관객-LED 거리 - 배우-LED 거리)`

LED 2.5m, 배우 183cm, 관객-LED 10m, 배우가 LED 앞 2m이면 **91.5%**입니다.
배우가 LED 평면에 있으면 **73.2%**입니다. 배우가 관객 위치에 도달하거나 지나가는 입력에는 경고하고 실루엣을 표시하지 않습니다.
이 기능은 정면 기준 원근 크기 비교입니다. 꺾인 물리 패널의 투시·관객 시선 높이·바닥 원근을 복원하지 않습니다.
발 위치는 기준 영역 안의 상대 좌표로 직접 조절하며, 실루엣 자체를 끌어서 옮길 수도 있습니다.

## 저장과 양방향 재사용

구도 저장은 LED 설정을 컷의 구도 상태에 포함합니다. 기존 자료에는 기본값으로 비어 있습니다.
공용 배치 이름을 입력해 **새 배치로 저장**하면 두 편집기에서 같은 목록으로 불러옵니다.
이미지 편집의 임시 설정은 이미지별로 유지합니다. 공용 배치와 파일 가져오기는 되돌리기 한 단계입니다.
공용 배치는 해당 설치판의 로컬 저장소에 유지되며 다른 컴퓨터·개발판·설치판 사이에는 **파일 내보내기 / 파일 불러오기**로 옮깁니다.
파일 형식은 `aimoviestorage-led-guides`, 버전 1입니다.

## 출력 분리

테두리·문구·실루엣은 3D 장면이나 원본 이미지 캔버스와 별도의 SVG입니다.
구도 프레임·배경판·레퍼런스 영상 렌더러는 기존 WebGL 캔버스만 읽으므로 LED 오버레이는 출력에 들어가지 않습니다.
검증용 이미지를 연 뒤 같은 공용 배치를 불러오면 가이드가 없는 시작 이미지에 최종 크롭 영역을 다시 겹쳐 확인할 수 있습니다.
